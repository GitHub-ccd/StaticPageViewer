Goal: If two or three succeed, combined performance should reach PR-AUC 0.400–0.408.

Experiment A: Missingness Indicators (Monitoring Gaps)

Hypothesis: Patients with no A1C in two years, no eGFR, or no lipid panel are at systematically higher risk — absence of monitoring as a risk signal in itself.

Item Detail
Features to create Binary flags: no_a1c_22mo, no_egfr_22mo, no_lipid_22mo, no_creatinine_22mo, plus a composite count
Source tables Existing lab dimension tables (already joined); check for NULL/missing
Effort Low — computed from existing feature tables, no new joins
Expected benefit Small incremental improvement
FE home TBD — likely A1C + eGFR or a new monitoring dimension

Experiment B: Care Utilization Patterns

Hypothesis: How patients use the health system (visit regularity, no-show rate, repeat ED attendance, care fragmentation across departments) carries predictive signal not captured by the current utilization dimension.

Item Detail
Features to create Visit frequency, no-show rate, ED bounce-back count, department fragmentation index, days between visits (variability)
Source tables cp__pat_enc, scheduling tables (need access confirmation)
Effort Medium — requires scheduling table access
Expected benefit Small incremental improvement
FE home Likely tbl_util_features_target (extend from 6 features)

Experiment C: Baseline Feature Recovery

Hypothesis: Of the ~373 columns in the original 854-feature baseline model not yet evaluated in the current 11-dimension approach, some subset (20–40 features) may carry residual signal.

Item Detail
Approach Compare tbl_baseline_features_target columns against current 11 joined features. Identify non-overlapping columns with non-trivial variance. Append top candidates and re-run H2O.
Source tables bsmh_ds_ph_wip.tbl_baseline_features_target (1,071 columns, 301,443 rows)
Effort Low — one H2O run on appended data
Expected benefit Small incremental improvement
FE home Standalone supplement (like the Pharm Subclass flags pattern)
