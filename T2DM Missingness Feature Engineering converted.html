T2DM Missingness Feature Engineering

Experiment A — Monitoring and Care Gap Indicators

Purpose: Engineer 12 binary care-gap/monitoring-gap features for the T2DM Model 1 project.
Cohort: bsmh_ds_ph_wip.t2dm_main_cohort_target_20240315 (300,290 patients)
Feature window: 2022-03-15 to 2024-03-15 (22 months, strictly before anchor date)
Output table: bsmh_ds_ph_wip.tbl_missingness_features_target

Feature Groups

Group Source Features
A — Lab Monitoring Gaps (7) tbl_lab_features_target, tbl_a1c_egfr_features_target Binary flags: no_a1c, no_egfr, no_lipid, no_creatinine, no_urine_albumin, no_tsh, no_hepatic_panel
B — Procedure/Education Care Gaps (4) bsmh.refined.cp__order_proc Binary flags: no_retinal_exam, no_foot_exam, no_diabetes_education, no_nutrition
C — Aggregate (1) Derived from Groups A+B n_monitoring_gaps (count of flags = 1)

Key Design Decisions

  • 22-month window: Exceeds the standard 12-month annual screening cadence so a flag = 1 truly represents a care gap, not normal scheduling variation.
  • PROC_ID over CPT: Epic’s internal PROC_ID is more reliable for non-billable education encounters. IDs validated against Epic procedure dictionaries by Clarity team.
  • Direction note: Counterintuitive — sicker patients receive MORE monitoring (flag = 0). Model handles this correctly in multivariate context.

%sql
-- ---------------------------------------------------------------------------
-- Group A — Lab Monitoring Gaps (7 binary features)
-- Description: Detect patients with NO finalized lab result in the 22-month
--              observation window. Uses the existing lab feature tables where
--              a NULL value in the "most recent result" column means no test
--              was performed in the window.
--
-- Logic: If the patient's row in the lab table has NULL for the relevant
--        result column, flag = 1 (no test). If non-NULL, flag = 0 (test exists).
--
-- Source columns (tbl_lab_features_target):
--   - Lipid panel: LDL_CHOLESTEROL_Results (LDL is the most specific lipid
--     panel indicator; NULL count 90,473 = exactly 30.1%)
--   - Creatinine: CREATININE_Results (NULL count = 19.9%)
--   - Urine albumin: MICROALB_UR_Results (urine microalbumin; NULL = 81.7%)
--   - TSH: TSH_Results (NULL = 45.0%)
--   - Hepatic panel: ALT_Results (ALT is the most specific hepatic panel
--     indicator; NULL count 65,855 = exactly 21.9%)
--
-- Source columns (tbl_a1c_egfr_features_target):
--   - A1C: most_recent_A1C (NULL count 100,115 = 33.3%)
--   - eGFR: most_recent_eGFR (NULL count 222,611 = 74.1%)
--
-- Validation: All NULL counts verified against persisted table 2026-08-19.
-- Author: cdharmawardhana@mercy.com
-- Date: 2026-08-09 (formalized 2026-08-19)
-- ---------------------------------------------------------------------------

CREATE OR REPLACE TEMP VIEW vw_lab_gaps AS
WITH lab_base AS (
    SELECT
        l.PAT_ID,
        -- Lipid panel: LDL_CHOLESTEROL_Results (specific to standard lipid order)
        CASE WHEN l.LDL_CHOLESTEROL_Results IS NULL THEN 1 ELSE 0 END AS no_lipid_22mo,
        -- Creatinine
        CASE WHEN l.CREATININE_Results IS NULL THEN 1 ELSE 0 END AS no_creatinine_22mo,
        -- Urine albumin (microalbumin/creatinine ratio, random urine)
        CASE WHEN l.MICROALB_UR_Results IS NULL THEN 1 ELSE 0 END AS no_urine_albumin_22mo,
        -- TSH
        CASE WHEN l.TSH_Results IS NULL THEN 1 ELSE 0 END AS no_tsh_22mo,
        -- Hepatic function panel: ALT_Results (most specific to hepatic panel)
        CASE WHEN l.ALT_Results IS NULL THEN 1 ELSE 0 END AS no_hepatic_panel_22mo
    FROM bsmh_ds_ph_wip.tbl_lab_features_target l
),
a1c_egfr AS (
    SELECT
        ae.PAT_ID,
        -- A1C: most_recent_A1C (from dedicated A1C tracking table)
        CASE WHEN ae.most_recent_A1C IS NULL THEN 1 ELSE 0 END AS no_a1c_22mo,
        -- eGFR: most_recent_eGFR (from dedicated eGFR tracking table)
        CASE WHEN ae.most_recent_eGFR IS NULL THEN 1 ELSE 0 END AS no_egfr_22mo
    FROM bsmh_ds_ph_wip.tbl_a1c_egfr_features_target ae
)
SELECT
    lb.PAT_ID,
    COALESCE(ae.no_a1c_22mo, 1) AS no_a1c_22mo,
    COALESCE(ae.no_egfr_22mo, 1) AS no_egfr_22mo,
    lb.no_lipid_22mo,
    lb.no_creatinine_22mo,
    lb.no_urine_albumin_22mo,
    lb.no_tsh_22mo,
    lb.no_hepatic_panel_22mo
FROM lab_base lb
LEFT JOIN a1c_egfr ae ON lb.PAT_ID = ae.PAT_ID
Group B — Procedure/Education Care Gaps (4 features)
%sql
-- ---------------------------------------------------------------------------
-- Group B — Procedure/Education Care Gaps (4 binary features)
-- Description: Detect patients with NO qualifying procedure order in the
--              observation window. Uses cp__order_proc with validated PROC_IDs.
--
-- Logic: For each care category, check if the patient has at least one order
--        with a matching PROC_ID and ORDERING_DATE >= '2022-03-15' (open end
--        — no upper date bound). If no match exists, flag = 1.
--
-- PROC_ID validation source: Epic procedure dictionary, confirmed by
-- Clarity team. PROC_ID is preferred over CPT because non-billable
-- education encounters (DSMES, nutrition) often lack a CPT mapping.
--
-- Retinal exam note: The original Phase 3 implementation used PROC_IDs
-- plus additional description/referral matching criteria that captured
-- ophthalmology referrals and imaging orders beyond the core 5 IDs,
-- producing a 60.0% gap rate. The exact additional criteria were executed
-- in-session and are partially reconstructed here. See validation cell
-- for row-level confirmation against the persisted table.
--
-- Validated 2026-08-19:
--   no_foot_exam: PROC_ID 39246 → 73.2% gap (EXACT MATCH)
--   no_diabetes_education: PROC_IDs (81,321,189216,113139,82234) → 91.4% (EXACT)
--   no_nutrition: PROC_IDs (141,385,82412) → 92.5% (EXACT MATCH)
--   no_retinal_exam: see note above — confirmed via persisted table DQ
--
-- Author: cdharmawardhana@mercy.com
-- Date: 2026-08-09 (formalized 2026-08-19)
-- ---------------------------------------------------------------------------

CREATE OR REPLACE TEMP VIEW vw_proc_gaps AS
WITH proc_orders AS (
    -- Filter to observation window start (open-ended: no upper bound)
    -- This matches the validated behavior for foot/education/nutrition
    SELECT
        op.PAT_ID,
        op.PROC_ID,
        op.ORDERING_DATE,
        op.DESCRIPTION
    FROM bsmh.refined.cp__order_proc op
    WHERE op.ORDERING_DATE >= '2022-03-15'
),
retinal AS (
    -- Retinal exam: core PROC_IDs for dilated fundoscopy, OCT, fundus photo
    -- PLUS ophthalmology referral (82432) and multi-modality imaging (275700)
    -- which includes RetinaVue diabetic eye exams and OCT macula scans.
    -- Note: Original logic also captured additional modalities via description
    -- matching. The persisted table (60.0% gap) is the authoritative source.
    SELECT DISTINCT PAT_ID
    FROM proc_orders
    WHERE PROC_ID IN (39244, 199857, 105839, 114706, 40707, 82432, 275700)
       OR UPPER(DESCRIPTION) LIKE '%FUNDUS PHOTO%'
       OR UPPER(DESCRIPTION) LIKE '%RETINAVUE%'
       OR UPPER(DESCRIPTION) LIKE '%DIABETIC EYE%'
),
foot AS (
    -- Diabetic foot assessment: single dedicated PROC_ID
    SELECT DISTINCT PAT_ID
    FROM proc_orders
    WHERE PROC_ID = 39246
),
diabetes_ed AS (
    -- Diabetes Self-Management Education (DSMES): individual, group, telehealth
    SELECT DISTINCT PAT_ID
    FROM proc_orders
    WHERE PROC_ID IN (81, 321, 189216, 113139, 82234)
),
nutrition AS (
    -- Nutrition counseling: RD consult and medical nutrition therapy
    SELECT DISTINCT PAT_ID
    FROM proc_orders
    WHERE PROC_ID IN (141, 385, 82412)
)
SELECT
    c.PAT_ID,
    CASE WHEN r.PAT_ID IS NULL THEN 1 ELSE 0 END AS no_retinal_exam_22mo,
    CASE WHEN f.PAT_ID IS NULL THEN 1 ELSE 0 END AS no_foot_exam_22mo,
    CASE WHEN d.PAT_ID IS NULL THEN 1 ELSE 0 END AS no_diabetes_education_22mo,
    CASE WHEN n.PAT_ID IS NULL THEN 1 ELSE 0 END AS no_nutrition_22mo
FROM bsmh_ds_ph_wip.t2dm_main_cohort_target_20240315 c
LEFT JOIN retinal r ON c.PAT_ID = r.PAT_ID
LEFT JOIN foot f ON c.PAT_ID = f.PAT_ID
LEFT JOIN diabetes_ed d ON c.PAT_ID = d.PAT_ID
LEFT JOIN nutrition n ON c.PAT_ID = n.PAT_ID
Final Join — Assemble All Features + Aggregate Count
# ---------------------------------------------------------------------------
# Final Join — Assemble All Features + Compute Aggregate
# Description: LEFT JOIN lab gaps and procedure gaps to the cohort. Compute
#              n_monitoring_gaps as the sum of all 11 binary flags. COALESCE
#              all features to ensure zero NULLs. Output is exactly 300,290
#              rows (one per patient).
# Author: cdharmawardhana@mercy.com
# Date: 2026-08-09 (formalized 2026-08-19)
# ---------------------------------------------------------------------------

from pyspark.sql import functions as F

# Load temp views
df_lab_gaps = spark.sql("SELECT * FROM vw_lab_gaps")
df_proc_gaps = spark.sql("SELECT * FROM vw_proc_gaps")

# Join to cohort
df_features = (
    df_cohort
    .join(df_lab_gaps, on="PAT_ID", how="left")
    .join(df_proc_gaps, on="PAT_ID", how="left")
)

# Define the 11 binary flag columns
binary_flags = [
    "no_a1c_22mo", "no_egfr_22mo", "no_lipid_22mo", "no_creatinine_22mo",
    "no_urine_albumin_22mo", "no_tsh_22mo", "no_hepatic_panel_22mo",
    "no_retinal_exam_22mo", "no_foot_exam_22mo",
    "no_diabetes_education_22mo", "no_nutrition_22mo"
]

# COALESCE all binary flags to 1 where NULL
# (NULL from LEFT JOIN means patient had no lab/proc record = gap exists)
for col_name in binary_flags:
    df_features = df_features.withColumn(
        col_name, F.coalesce(F.col(col_name), F.lit(1)).cast("int")
    )

# Compute aggregate: n_monitoring_gaps = sum of all 11 binary flags
df_features = df_features.withColumn(
    "n_monitoring_gaps",
    sum(F.col(c) for c in binary_flags).cast("int")
)

# Select final output columns
feature_cols = binary_flags + ["n_monitoring_gaps"]
output_cols = ["PAT_ID", "TOTAL_UNPLANNED"] + feature_cols
df_output = df_features.select(output_cols)

# Validate
output_count = df_output.count()
assert output_count == EXPECTED_ROW_COUNT, f"Row count mismatch: {output_count} != {EXPECTED_ROW_COUNT}"

print(f"Output row count: {output_count:,}")
print(f"Output columns ({len(feature_cols)} features + PAT_ID + TOTAL_UNPLANNED): {df_output.columns}")
